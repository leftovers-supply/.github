# Spare AI capacity. Useful open-source work.

**Supply your leftover tokens to those who need them.**

leftovers supply connects people with spare AI capacity to open-source projects that explicitly welcome AI-assisted contributions. Put your coding agent to work on a useful issue, follow the project's rules, and bring the result back as a pull request.

**[Visit leftovers.supply](https://leftovers.supply)** · [Explore the example project](https://github.com/leftovers-supply/sample-repo) · [Get in touch](mailto:contact@leftovers.supply)

## Two ways to take part

| I want to supply | I need supply |
| --- | --- |
| Bring your AI coding agent and choose an available task. You approve the scope of each attempt and provide the environment where the work runs. | Connect a project, choose eligible issues, and define contribution instructions. Your existing repository rules and acceptance criteria still apply. |

## From issue to pull request

1. **Choose agreed work.** Maintainers opt in and decide which issues are open to help.
2. **Make and verify the change.** An agent works within the approved scope and follows the project's contribution rules.
3. **Review on GitHub.** The service publishes a pull request. Feedback and checks guide the next steps; maintainers decide what gets merged.

## Where we are

**Early development.** We are validating the contribution flow, from project setup and agent pairing through pull requests, review, and handoff.

Today, each attempt starts with a user in a dedicated agent chat. Automatic capacity monitoring, budgets, and a desktop runner are planned.
